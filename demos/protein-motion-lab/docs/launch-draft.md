# Draft project announcement

I built a small protein-motion viewer from a real OpenMM simulation of ubiquitin.

You can rotate the backbone, scrub through time and inspect how much it moves
after removing whole-protein rotation and translation. The data, simulation
settings and code are included.

This first release is deliberately a short software demo. Next I want to use the
same interface to make longer, properly checked research simulations easier to
inspect and discuss.

If you work on molecular simulation or scientific visualization, I would value
feedback on what would make this useful in your workflow.
